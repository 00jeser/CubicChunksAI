# Документация Cubic Chunks

Мод заменяет колонки фиксированной высоты кубами. Целевая платформа порта — NeoForge `26.1.2.116` и Minecraft `26.1.2`. Сборка на этой версии. Игра до кубов в мире ещё не доведена.
