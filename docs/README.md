# Документация Cubic Chunks

Мод переписывает хранение мира Minecraft: вместо колонок фиксированной высоты используются кубы, и вертикальный диапазон мира становится практически неограниченным. Целевая платформа этого репозитория — NeoForge и Minecraft 1.21.6. Мод ещё не готов к игре.
