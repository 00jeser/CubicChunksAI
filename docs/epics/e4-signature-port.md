# E4 — Сигнатуры ванили 26.1

**Этап ТЗ:** 1. Порт собирается  
**Статус:** planned  
**Зависимости:** [E3](e3-dasm-mixin.md)  
**Следующий:** [E5](e5-world-style.md)

Жёстко после E3. Список красных файлов — выход E3-S3. Сигнатуры брать из исходников NeoForge `26.1.2.116` в Gradle, не по памяти.

---

## Цель

`./gradlew compileJava test` зелёный на тестах, которые не помечены `@Disabled`. Клиент доходит до главного меню. Мир ещё может падать при входе — это E5–E8.

---

## Scope

- Механическая замена вызовов, которые сменили имя или тип между 1.21.6 и 26.1.2.
- Обязательный минимум из заметки NeoForge: `ChunkPos.containing`, `ChunkPos.pack`, `ChunkPos.unpack`; GUI — `GuiGraphicsExtractor` и `extractRenderState` там, где мод рисует экран.
- Конструктор `ServerLevel`, на который вешается `MixinServerLevel.cc_onInit`.
- Кодеки пакетов `CCClientbound*`, если сменился `StreamCodec` / `CustomPacketPayload`.
- Тесты мода, которые падают только из-за тех же переименований.

---

## Out of scope

- Включение `cc_isCubic` из конфига — [E5](e5-world-style.md). Тело `cc_onInit` остаётся пустым.
- Замена `passThrough`, синусоиды, `cc_save == false`, константы света — E6, E10, E11, E12.
- Снятие `@Disabled` у тестов, которым нужны клиентские миксины или живой сервер. Рядом с аннотацией остаётся эпик: сеть — [E7](e7-network-cache.md), сервер — [E6](e6-server-load.md).
- Перенос `movetoforgesourcesetlater` — [E18](e18-neoforge-events.md).
- Новый поведение экрана создания мира — [E19](e19-world-ui.md). Здесь только компиляция `MixinCreateWorldScreen`.

## Архитектура эпика

### Решение

Порт сигнатуры не меняет смысл метода. Если ванильный метод исчез, а не переименован, ставится `// E4: нет в 26.1.2` и задача в эпик, который владеет подсистемой. Молчаливая новая логика запрещена.

### Состояние к концу E4

```text
Сборка мода
├── compileJava зелёный
├── test зелёный на всём, что без @Disabled
└── runClient доходит до главного меню

Поведение мира
└── как на 1.21.6-порте: синусоида, save=false, свет=MAX, стиль не ставится
```

Нет: принятого куба на клиенте как критерия этого эпика.

### Поток правки

1. Открыть красный файл из списка E3.
2. Найти тот же вызов в исходниках 26.1.2.
3. Повторить ванильное переименование (`new ChunkPos(long)` → `ChunkPos.unpack`, `asLong` → `pack`, `Screen.render` → `extractRenderState`).
4. Если цели миксина `@At` больше нет — обновить target по фактическому методу, не выкидывать инъекцию.
5. Прогнать компиляцию пакета и тест этого пакета.

### Модули

| Тема | Путь |
| --- | --- |
| Сервер | `mixin/core/common/server/**` |
| Уровень и куб | `world/level/**`, `mixin/core/common/world/**` |
| Клиент GUI | `client/gui/**`, `mixin/core/client/gui/**`, `mixin/core/client/worldselection/MixinCreateWorldScreen.java` |
| Рендер | `mixin/core/client/renderer/**` |
| Сеть | `network/**` |
| Тесты | `src/test/java/**` |

### Инварианты E4

1. `MixinChunkMap.cc_save` по-прежнему возвращает `false` (ARCHITECTURE §10.6).
2. `CubeStatusTasks.generateNoise` по-прежнему пишет синусоиду. Остальные шаги — `passThrough`.
3. `MixinLevelLightEngine` по-прежнему возвращает максимальную яркость в кубическом уровне.
4. Префикс `cc_` сохраняется.
5. Пустой `cc_onInit` не начинает ставить стиль «раз уж конструктор открыт».

## Критерии приёмки эпика

1. `./gradlew compileJava test` зелёный.
2. Клиент показывает главное меню.
3. `cc_save` всё ещё `return false`. `generateNoise` всё ещё синусоида.
4. **Регрессия:** тесты ядра из E2 зелёные; `dasm` версия из E3 не сменена.
5. **Документация:** ARCHITECTURE §3 не переписывается (поток тот же). В README эпиков статус не `done`, пока меню не увидено руками.

**Не требуется в E4:** вход в кубический мир, рисунок блоков, сохранение.

## Риски и решения

| Риск | Решение |
| --- | --- |
| Конструктор `ServerLevel` потерял параметры, и инъекция молча не вешается | S4.2: `injectorsDefaultRequire = 1` уже в конфиге `core`; падение загрузки чинится новым target, не `require = 0` |
| Экран создания мира больше не имеет `WorldTab` | S4.3 компилирует миксин на фактический класс; поведение кнопки — E19 |
| Тест зелёный, потому что его исключили | S4.4 запрещает новый `@Disabled` без эпика |
