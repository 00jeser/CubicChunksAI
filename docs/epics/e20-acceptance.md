# E20 — Приёмка

**Этап ТЗ:** 6. Стык с NeoForge и приёмка  
**Статус:** planned  
**Зависимости:** [E11](e11-persistence.md), [E13](e13-surface-features.md), [E16](e16-ticks-poi.md), [E17](e17-spawn.md), [E18](e18-neoforge-events.md), [E19](e19-world-ui.md)  
**Следующий:** нет

Финал. Код подсистем не переписывать: дыру, найденную прогоном, чинит эпик-владелец, этот эпик только собирает сценарий и закрывает документы.

---

## Цель

Сценарий ТЗ §7 проходит руками на NeoForge `26.1.2.116`. `./gradlew test` зелёный. В README эпиков статусы совпадают с фактом. ARCHITECTURE не описывает снятые заглушки как живые.

---

## Scope

- Прогон §7 по пунктам, с логом или снимком на каждый.
- Ванильный мир `CHUNK` и кубический мир в одном клиенте по очереди.
- Сверка инвариантов ARCHITECTURE §10 с кодом: `cc_save`, свет, `passThrough`, префикс `cc_`.
- Снятие `@Disabled`, у которых владелец уже закрыт. Оставшийся `@Disabled` ссылается на причину вне ТЗ либо тест переписан.
- Обновление `README.md` корня: цель платформы `26.1.2`, мод играбелен только если §7 зелёный. До зелёного §7 строка «не играбелен» остаётся.

---

## Out of scope

- Новая механика. Любой пробел §7 — возврат в эпик-владелец, не патч «здесь по-быстрому».
- Fabric, OptiFine, миграция старых сейвов, линейка 26.2.
- Нагрузочный миллион блоков как бенчмарк. Достаточно уйти за ванильную высоту и на Y=10000.
- Включение `longRunTest`, пока он выключен комментарием в `build.gradle` и ни один эпик не завёл тест с этим тегом.

## Архитектура эпика

### Решение

Приёмка читает ТЗ §7 как чеклист и не заводит вторую формулировку «готовности». Расхождение чеклиста и ТЗ правится в ТЗ, не в устной оговорке.

### Состояние к концу E20

```text
Релизный смысл дерева
├── мир CUBIC сохраняется
├── мир CHUNK ванильный
├── свет, высота, шум, сущности, тики, спавн — живые
└── README эпиков: done только у пройденных

Нет новых полей относительно E19
```

### Поток прогона

1. `./gradlew test` на Java 25.
2. Клиент до меню.
3. Создать мир переключателем E19, проверить пункты §7.3–§7.7.
4. Добавить измерение `CHUNK` по `ServerConfig` и проверить §7.8.
5. Открыть отдельно ванильный мир при флаге создания `false` и стиле `CHUNK` — §7.9.
6. Пройтись по ARCHITECTURE §10 и вычеркнуть формулировки, которые эпики уже сменили, если эпик забыл документ.

## Критерии приёмки эпика

1. Все пункты ТЗ §7 отмечены пройденными в заметке прогона.
2. `./gradlew test` зелёный.
3. Ванильный мир не превращён в кубы.
4. **Регрессия:** перечислена прогоном §7, а не отдельным сюжетом.
5. **Документация:** ARCHITECTURE, README эпиков, корневой README.

**Не требуется в E20:** бенчмарк на миллион блоков, Fabric, миграция старых миров.
