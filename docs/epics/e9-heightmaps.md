# E9 — Карты высот

**Этап ТЗ:** 3. Мир переживает перезапуск  
**Статус:** planned  
**Зависимости:** [E8](e8-render.md)  
**Следующий:** [E10](e10-lighting.md)

После видимой синусоиды. Параллельно с E12 можно, файлы куба (`CubeAccess`, `LevelCube`, `ProtoCube`) — этот эпик. `CubeStatusTasks` не трогать: шум остаётся у E12.

---

## Цель

`CubeAccess` больше не кидает `UnsupportedOperationException` на картах высот. Высота колонки считается по загруженным кубам через дерево `SurfaceTracker*`. `getHeight` не возвращает константу `SUPERFLAT_HEIGHT`.

---

## Scope

- Методы heightmap на `CubeAccess`, `ProtoCube`, `LevelCube`.
- Запись в `SurfaceTrackerLeaf` при `setBlockState`.
- `ColumnCubeMap`: какие Y кубов загружены в колонке.
- Отдача карт в пакет как `Map<Heightmap.Types, long[]>`, дырку E7 закрыть данными, не новым пакетом.
- Юнит-тесты ядра на дерево остаются зелёными; мод добавляет тест «блок меняет высоту».

---

## Out of scope

- Свет от высоты — [E10](e10-lighting.md).
- Поиск спавна через `SpawnPlaceFinder` — [E17](e17-spawn.md). Дерево здесь только хранит и читает.
- Сохранение узла дерева на диск — [E11](e11-persistence.md). В памяти дерево живёт с кубами.
- Замена синусоиды. Высота синусоиды должна читаться честно, это и есть проверка.

## Архитектура эпика

### Решение

Колонка не хранит плоский массив на весь `int`. Высота колонки — дерево ядра. Куб хранит свои `Heightmap` для пакета и для шага генерации. Грязная колонка пересчитывается при чтении, как уже делает `SurfaceTrackerNode`.

### Состояние к концу E9

```text
CubeAccess
├── heightmaps: EnumMap<Heightmap.Types, Heightmap>
├── getHeightmaps() не кидает
└── getHeight(type, x, z) из карты куба

Колонка (на уровне)
├── ColumnCubeMap
└── SurfaceTracker* по типам ванильных карт
```

Нет: сериализации дерева. Нет: `SpawnPlaceFinder` в спавне игрока.

### Поток обновления

1. `setBlockState` на `LevelCube` / `ProtoCube` помечает локальную колонку грязной.
2. `getHeight` куба считает её из секций куба, если грязная.
3. Тот же апдейт поднимается в `SurfaceTrackerLeaf` колонки.
4. `ColumnCubeMap` добавляет Y при загрузке куба и убирает при drop.
5. Пакет E7 начинает писать `long[]` локальных карт. Клиент кладёт их в куб и не пересчитывает мир.

### Модули

| Тема | Путь |
| --- | --- |
| Заглушки, которые снять | `world/level/cube/CubeAccess.java` |
| Куб | `LevelCube.java`, `ProtoCube.java` |
| Дерево | `CubicChunksCore/.../heightmap/surfacetrackertree/` |

### Инварианты E9

1. `getHeightmaps` и `getOrCreateHeightmapUnprimed` не кидают.
2. Высота колонки не сканирует все кубы мира линейно на каждый запрос: либо дерево, либо грязный бит.
3. Выгрузка куба убирает его Y из `ColumnCubeMap`. Запрос высоты не возвращает блок выгруженного куба.
4. `SUPERFLAT_HEIGHT` не используется в `getHeight`.

## Критерии приёмки эпика

1. Поставленный игроком блок меняет высоту колонки.
2. Выгрузка верхнего куба уменьшает высоту.
3. Клиент после пакета читает ту же высоту, что сервер.
4. **Регрессия:** E8 картинка синусоиды, E7 forget, E6 генерация.
5. **Документация:** ARCHITECTURE §2.

**Не требуется в E9:** запись на диск, спавн, свет.
