# E13 — Поверхность, карверы, фичи

**Этап ТЗ:** 4. Ванильная генерация  
**Статус:** planned  
**Зависимости:** [E14](e14-structures.md)  
**Следующий:** [E17](e17-spawn.md)

После структур: ванильный порядок шагов — surface и features видят старты. Методы в `CubeStatusTasks`: `generateSurface`, `generateCarvers`, `generateFeatures`. Шум и биомы не переписывать.

---

## Цель

Поверхность куба получает покров биома, карверы вырезают объём, фичи (руда, растительность, озёра) ставят блоки в границы куба и не обрезаются ванильной высотой измерения.

---

## Scope

- Три шага `CubeStatusTasks`, сейчас `passThrough`.
- Фича, чья позиция Y попала в куб, ставит блок здесь, даже если Y вне ванильного min/max.
- Карвер не затирает структуру, которую E14 уже поставила, сверх того, как это делает ваниль.
- Ограничение радиуса фичи соседними кубами из кэша генерации `StaticCache3D`.

- Структурные старты — уже [E14](e14-structures.md).

## Архитектура эпика

### Решение

Шаг работает в объёме одного куба плюс соседний кэш, который пирамида и так передаёт. Фича не сканирует мир по вертикали целиком.

### Состояние к концу E13

```text
CubeStatusTasks
├── generateSurface   пишет покров
├── generateCarvers   вырезает
└── generateFeatures  руда и растительность

HYBRID
└── эти три метода остаются passThrough
```

Нет: своего реестра фич.

### Поток шага

1. Пирамида вызывает шаг на `ProtoCube`.
2. Позиции переводятся в блоки через `Coords` и `CubePos.minCubeY`.
3. Блок вне этого куба не пишется этим вызовом: его напишет соседний куб, когда дойдёт до того же шага.
4. `StaticCache3D` даёт соседние `ProtoCube`, если ваниль читает соседний чанк.
5. На `HYBRID` метод сразу возвращает куб как `passThrough`.

### Модули

| Тема | Путь |
| --- | --- |
| Шаги | `world/level/cube/status/CubeStatusTasks.java` |
| Кэш соседей | `util/StaticCache3D.java` |
| Колонка в кубическом контексте | `world/level/chunk/status/CCChunkStatusTasks.java` |
| Ориентир | `src_old/.../levelgen/feature`, `carver`, `placement` |

### Инварианты E13

1. `CUBIC`: после трёх шагов `passThrough` на них нет.
2. `HYBRID` и `CHUNK`: кубовые копии этих шагов блоки не пишут.
3. Фича не ставит блок в чужой куб.
4. Загруженный из NBT куб шаги не повторяет (E11).

## Критерии приёмки эпика

1. Новый мир: поверхность биома, пещера, хотя бы одна ванильная фича.
2. Пещера, пересекающая границу кубов, непрерывна.
3. `HYBRID` не получает второй покров от кубового шага.
4. **Регрессия:** E12 шум, E14 структуры на месте, E10 свет в пещере, E11 перезапуск не стирает фичу.
5. **Документация:** ARCHITECTURE §3.

**Не требуется в E13:** мобы, POI, чужие генераторы.
