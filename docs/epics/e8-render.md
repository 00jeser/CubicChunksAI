# E8 — Рендер секций

**Этап ТЗ:** 2. Кубический мир виден  
**Статус:** planned  
**Зависимости:** [E7](e7-network-cache.md)  
**Следующий:** [E9](e9-heightmaps.md)

Последний эпик жёсткого порядка. После него цепочки E9–E11 и E12–E14 можно параллелить по правилам их шапок. Этот эпик трогает `mixin/core/client/renderer/**` и `ClientCubeCache` только чтением.

---

## Цель

Игрок в кубическом мире видит синусоиду из `SMOOTH_STONE`. Секции берутся из `LevelCube` в клиентском кэше. Вертикальный радиус — `verticalViewDistance`.

---

## Scope

- `MixinViewArea` строит область по трём осям.
- `MixinSectionRenderDispatcher$RenderSection` и `MixinRenderRegionCache` читают секцию куба.
- `MixinSectionOcclusionGraph` обходит соседей по Y, не только по колонке.
- `MixinLevelRenderer` держит кубическую область.
- Экран загрузки показывает статусы кубов, если ванильный прогресс больше не в колонках (`CubicLevelLoadingScreen`).

---

## Out of scope

- Честный свет — [E10](e10-lighting.md). Рисовать тем, что уже лежит в секции. Не оставлять вечный `MAX_LEVEL` как способ «сделать видимым»: это всё ещё код E10, здесь его не усиливать.
- Карты высот для отсечения — [E9](e9-heightmaps.md).
- Отладочные свойства `cubicchunks.debug.heightmaprenderer` и класс `DebugVisualization`. Класса нет, оверлей не добавлять.
- Смена меша на GUI-картинку чанка.

## Архитектура эпика

### Решение

Видимая секция существует, только если `ClientCubeCache` уже содержит куб, которому она принадлежит. Рендер не шлёт пакеты и не генерирует.

### Состояние к концу E8

```text
CubicLevelRenderer
└── ViewArea
    ├── центр = куб игрока
    ├── радиус XZ = ванильная дистанция
    └── радиус Y = CommonConfig.verticalViewDistance

RenderSection
└── источник блоков = LevelChunkSection куба
```

Нет: своего буфера блоков в рендере. Нет: чтения региона.

### Поток кадра

1. Клиентский тик знает позицию игрока и переводит её в `CubePos` через `Coords.blockToCube`.
2. Если центр или радиус сменились, `ViewArea` перестраивает набор секций.
3. Occlusion идёт по соседям секции, включая верх и низ.
4. Меш берёт `BlockState` из секции. Промах кэша — пустая секция, не синхронная загрузка.
5. Экран загрузки, пока уровень не готов, рисует статусы из `CloProgressListener` и не создаёт кубы.

### Инварианты E8

1. ARCHITECTURE §10.7: рендер не читает диск и не парсит toml заново каждый кадр. Радиус кэшируется при смене конфига.
2. Один `ViewArea` на клиентский уровень, не на все измерения сразу (ARCHITECTURE §11).
3. `CHUNK`-уровень использует ванильный `ViewArea` без кубического радиуса Y.
4. `MixinLevelLightEngine` в этом эпике не менять.

## Критерии приёмки эпика

1. Новый мир: игрок стоит у камня синусоиды, блоки видны.
2. `verticalViewDistance=2` прячет далёкие по Y кубы, которые при 8 видны.
3. Ванильный уровень `CHUNK` рисуется как раньше, без кубической сетки.
4. **Регрессия:** E7 пакеты и кэш, E6 серверный куб, E4 меню, E5 стили.
5. **Документация:** ARCHITECTURE §6.

**Не требуется в E8:** сохранение, ночь со сменой яркости, биомы, мобы.
